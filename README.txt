ФОТО:

МУЗЫКА:
Если хочешь добавить музыку, положи файл с названием music.mp3 рядом с index.html. Воспроизведение запускается после нажатия пользователем — так работают ограничения браузеров.

Сайт работает локально. Если будешь отправлять его Нурсулу ссылкой, его нужно разместить на хостинге; ZIP сам по себе не является веб-ссылкой.
